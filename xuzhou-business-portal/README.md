# 徐州招商业务台

这是给零 IT 基础业务人员使用的独立前端。它与开发者使用的 QwenPaw 控制台分开，但不复制后端、账号、台账或钉钉配置；所有数据和权限仍由现有 QwenPaw 服务端决定。

## 业务页面包含什么

- 页面内使用手册：右上角“使用手册”用六个步骤解释从发现网页到人工确认结果的全流程，
  并分别说明业务人员、机器和管理员能做与不能做的事；同时为维护人员列出接口复用关系、
  常见故障排查顺序和安全扩展边界。打开手册不会修改台账或调用业务动作。

- 登录、注册和当前用户：复用 /api/auth/*。
- 平台用户管理：管理员复用 /api/users 创建、停用和恢复账号。
- 徐州团队名册：管理员通过 /api/xuzhou-investment-ledger/team/* 授权用户读取共享台账。创建账号不等于已获徐州台账权限。
- 材料队列：分别展示“仅发现候选”和“已保存页面材料”，避免把标题、链接或网页快照误当成正式证据。
- 人工材料入账：业务人员可登记自己有权使用、但服务器无法访问的网页摘录、授权文件或小型关键附件；服务端保存提交人、时间、哈希与访问方式，并明确标记为人工提交，不伪装成服务器抓取。
- 来源与学习：团队成员可选择机器只给建议、自动调整阅读顺序或受控重排既有固定来源配方，并可在业务页启用/暂停每日一次的受限学习计划；该计划只整理已有结果，不访问网页、不创建证据或对外联系。
- 人工补充公开来源：团队成员可提交一个无需账号、Cookie、令牌、API Key 或付费权限的公开网页；服务器先做网址安全、robots、公开访问和同域跳转检查，只有通过后才按低频范围发现候选。付费或授权 API 不能在页面填写，必须由开发者在后端按供应商许可接入。
- 正式线索和招商跟进审批：复用台账的只读看板与受限审批接口。页面只提交人工判断、六项核对、负责人和下一步，不能改写网页、证据或操作者。
- 来源与学习：业务人员可登记、启停未来来源分级域名，并选择机器只给建议、自动排序，或在明确授权后重排既有固定来源配方。学习只读取已留痕材料、人工审批和实际结果；不能新增域名、关键词、产业范围、证据或外部动作。
- 钉钉日报：管理员复用既有的单人固定日报配置；页面不展示会话 ID，也不能任意指定收件人。
- 徐州 Agent 对话：调用 /api/console/chat，并把会话保存为当前账号自己的 `xuzhou-business` 会话。业务页用既有 /api/chats 读取、恢复和归档这些会话；不会混入该用户在开发者控制台中的其他对话，也不会显示其他用户的会话。

## 人机分工

1. 机器发现公开候选，记录标题、链接、摘要和时间。
2. 服务器在来源规则允许时保存页面文本、哈希和采集时间，形成“已保存页面材料”。
3. 业务人员阅读材料、记录判断；如果网页仅能由人合法访问，可在“人工材料入账”登记关键摘录、访问方式和有权使用声明。
4. 服务器材料可请求重新抓取和核验；人工材料始终明确标识为人工提交，不被自动升级成服务器抓取事实，也不进入机器自动评分。
5. 业务人员在招商跟进审批卡中逐项核对、指定负责人和下一步；对人工材料线索还可记录实际结果，供来源阅读优先级学习。审批通过只表示进入内部人工跟进池，并不表示企业同意来徐州、签约、投资或系统已联系企业。

人工补充公开来源属于另一条“让机器发现候选”的通道：人只提交正常公开网址；服务器决定
能否读取，且从不请求或保存账号、Cookie、密码或 API Key。检测通过也只会产生待人工核验
候选。若人能合法访问、服务器不能访问，应使用人工材料入账；若来源是付费 API 或授权数据
接口，应交给开发者在服务端依供应商许可实现，不能把密钥粘贴到业务页面。

## 访问地址和构建

生产镜像会把本目录复制为 /app/business-portal，并用 QWENPAW_BUSINESS_PORTAL_STATIC_DIR 在与 QwenPaw API 相同的域名挂载为：

/business/

例如现有控制台位于 https://example.com/ 时，业务页位于 https://example.com/business/。同源部署意味着页面可直接安全地调用既有 /api，不需要额外 CORS、账号同步或另一套数据库。

## 安全边界

页面只保存浏览器的 QwenPaw Bearer token，不保存密码。业务事实、来源、证据、操作者、团队名册和账号权限都由服务端校验。人工材料提交不得包含密码、Cookie、访问令牌、受保护个人信息或无权使用的内容；附件只允许小型 PDF、图片或文本，服务端不读取用户浏览器会话。业务聊天的发送、停止、会话恢复和归档都需要同一登录令牌；前端仅查询当前账号、`console` 通道、且会话 ID 属于 `xuzhou-business` 命名空间的记录（兼容上一版业务页产生的同账号会话）。服务端仍会按照已认证用户选择其有权访问的智能体，不信任浏览器提交的用户身份。

页面内手册只负责解释产品，不是新的授权来源。实际权限始终以服务端认证、平台角色和徐州
团队名册为准；修改手册文字不能扩大任何用户或机器的权限。
