# 双端页面内使用手册维护说明

## 两个入口

- QwenPaw 徐州招商工作台：标题区“使用手册”，面向业务人员、管理员和开发维护人员。
- 独立徐州招商业务页：顶栏“使用手册”，面向零 IT 基础业务人员，同时保留维护说明。

>
> 两个入口都必须是只读组件。打开、切换章节和关闭手册不能发起新增、审批、核验、学习、
> 用户管理或钉钉配置请求。

## 必须保持一致的核心表述

1. 机器负责发现、保存、重新核验、提示风险、排序、审计和生成简报。
2. 业务人员负责判断招商价值、核对事实、指定负责人、决定下一步和记录真实结果。
3. 管理员额外负责账号、徐州团队名册、运行计划与钉钉日报配置。
4. 候选链接不是材料；保存的页面或人工授权材料不是正式证据；正式证据不是招商成果。
5. 入证、入跟进池、签约、落地是四个不同状态，不能互相替代。
6. 学习只能调整既有内容的阅读优先级；不能自动新增来源、关键词、产业、事实、证据或外联动作。

## 修改和扩展顺序

新增功能或状态时，按以下顺序更新：

1. 服务端权限和审计规则；
2. QwenPaw 工作台操作入口与状态文案；
3. 独立业务页操作入口与状态文案；
4. 两端页面内使用手册；
5. 本文和相关专项运维文档；
6. 类型检查、前端构建与插件回归测试。

新增免费公开网页来源时走页面内“人工补充公开来源”；付费或授权 API 必须在后端按供应商
许可接入。新数据字段必须保留来源、采集时间、操作者和审计轨迹。若新增动作可能影响外部
人员、改变正式事实或扩大数据访问范围，不能只改前端，必须先增加服务端授权和审计。

## 常见故障排查

按“登录认证 → 徐州团队权限 → API 响应 → 数据状态 → 页面渲染”的顺序检查。手册显示正常
不代表业务接口正常；业务接口异常也不应阻止用户打开手册查看排查说明。
