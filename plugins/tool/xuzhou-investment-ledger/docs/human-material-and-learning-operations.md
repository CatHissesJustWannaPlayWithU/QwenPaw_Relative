# 人工授权材料与来源学习操作说明

这份说明适用于两类人：使用“徐州招商业务台”的业务人员，以及维护 QwenPaw 插件的开发
人员。它解决一个现实问题：有些网页业务人员可以合法打开，但服务器因为登录、动态渲染、
robots 或站点策略无法抓取。此时不能把“服务器抓不到”误解为“材料没有价值”。

## 先分清两条材料通道

| 通道 | 谁取得材料 | 系统记录什么 | 可以自动做什么 | 绝不能声称什么 |
| --- | --- | --- | --- | --- |
| 服务器抓取材料 | 服务器从允许访问的公开页面取得 | 页面文本、采集时间、哈希、来源和后续重新核验结果 | 可用于固定规则的证据分类、评分和服务器重新核验 | 企业已同意来徐州或招商已经成功 |
| 人工授权材料 | 已授权业务人员从自己有权访问的页面、文件或导出中取得 | 提交人、提交时间、访问方式、摘录、材料包哈希、可选小附件哈希 | 支持人工研判、招商审批和来源阅读优先级学习 | 服务器已经登录、抓取或核验了该页面 |

人工授权材料并不是“低级材料”。它解决的是访问能力差异；其边界是由人对材料来源、使用权和
关键事项负责，而不是把人的权限借给服务器或模型。

## 业务人员：应该怎样操作

### 1. 判断是否应走人工材料通道

适合使用的情形包括：

- 页面必须使用你所属组织的正常账号登录；
- 页面依赖浏览器动态加载，服务器无法稳定呈现；
- 网站按 robots 或安全规则拒绝服务器，但你能合法阅读公开内容；
- 你持有有权使用的 PDF、网页导出或正式文本。

不适合提交的内容包括密码、Cookie、访问令牌、浏览器导出配置、个人敏感信息，以及你没有
保存或用于内部招商研判权限的材料。

### 2. 在“人工材料入账”填写什么

1. 填企业/机构、产业、页面或文件标题和来源链接；链接必须是正常域名，不能是本机、内网
   IP、含账号密码的地址，也不能带访问令牌、会话或签名下载参数。若你打开的是带令牌的
   临时链接，请填写不含凭据的正常页面地址，并在“访问方式”中如实说明。
2. 选择你如何访问到材料。这个选择会被审计，不会让服务器尝试使用你的登录身份。
3. 只摘录支持本次判断的关键原文，写明页面显示日期；没有日期就如实留空。
4. 选择来源属性和材料完整度。二手媒体、模糊转载或仅标题线索应如实选择较低等级。
5. 如有必要，上传不超过 512KB 的关键截图、PDF 或文本导出；附件不是可执行文件，也不会
   被服务器当作网页脚本运行。
6. 勾选“我有权使用该材料”后提交。服务器生成提交时间、证据 ID、材料哈希和签名；浏览器
   不能指定提交人、时间、哈希、线索 ID 或服务器抓取状态。

提交成功的意思是“材料已可追溯地进入团队内部台账”，不是“企业事实已由服务器确认”，更
不是“企业已承诺落地”。

### 3. 人工材料怎样变成招商行动

人工材料入账后，线索详情会显示“服务器材料”和“人工授权材料”的数量。接下来的人机分工
如下：

1. **机器**保留材料、显示来源方式、提示已有风险并留审计；不会登录原网页、修改材料、自动
   给企业发消息或下招商结论。
2. **业务人员**核对主体是否一致、关键事项是否完整、是否与徐州产业匹配；对融资、合作、
   扩张等关键说法应寻找独立公开来源或一手材料交叉验证。
3. **业务人员**完成招商跟进审批卡：指定负责人、完成日期、实际下一步和风险处理。审批通过
   只表示纳入内部人工跟进池。
4. **业务人员**在有真实业务进展后记录“有实质推进、落地、暂缓、未转化或无效”。系统会
   把这次反馈只归因到本线索中登记的人工材料来源，不会因为同一线索还有别的网页，就把一
   次人工判断复制给其他域名。此记录只用来改善未来来源阅读优先级，不会改写原始材料、评
   分或线索状态。

如果材料确实是公开页面，且之后服务器的访问条件恢复，可以另走原有的服务器重新核验流程。
服务器重新抓取成功时会新增独立服务器材料；不会覆盖或冒充此前的人工材料。

## 业务人员：来源学习到底在学什么

“来源与学习”页面只学习**下一批材料先看哪个来源**，不学习或推断企业的投资意愿。

- 默认模式是“自动调整业务队列优先级”：同一来源的已保存材料、人工审批和实际结果会形成
  可解释统计；样本不足时只显示“仅供参考”。
- “只给建议”会停用自动排序。
- “自动排序，并重排固定来源配方”必须由登录团队成员明确选择并留下原因。它只能重排系统
  现有的固定配方，不能新增域名、关键词、产业范围或 Skill。
- “每日学习节奏”可由团队成员启用或暂停固定的每天 03:35（北京时间）计划。计划只整理
  已有材料、审批和结果反馈；不会立即运行，不访问网页、不新增证据，也不会代替人下招商
  结论。若提示已由其他智能体托管，应在原托管处或由管理员统一管理，避免重复运行。
- 任何团队成员可登记、启用或停用未来来源分级域名。登记不等于立即抓取，服务器仍按公开
  访问、robots、跳转、响应大小和安全规则决定是否可以访问。

当某一个来源占近期候选的大多数时，页面会显示来源集中提醒。正确的处理是由人登记或启用
更多合规来源，而不是让机器绕过访问限制或把单一媒体报道自动升级为企业事实。

## 开发维护：接口与不变量

### 接口

- `GET/POST /api/xuzhou-investment-ledger/human-evidence`
  - POST 仅接受材料业务字段、访问方式、明确声明和受限小附件；认证身份由
    `get_current_principal()` 取得。
- `GET /api/xuzhou-investment-ledger/adaptive-learning`
  - 返回当前学习模式、来源表现、集中度解释和不可自动执行的事项。
- `POST /api/xuzhou-investment-ledger/adaptive-learning/policy`
  - 只接受三种固定模式和变更理由；不得接受权重、来源、URL、用户 ID 或证据字段。
- `POST /api/xuzhou-investment-ledger/adaptive-learning/leads/{lead_id}/human-material-outcome`
  - 只接受受控结果枚举和说明；目标线索必须已有 `human_attested_material`。
- `GET/POST /api/xuzhou-investment-ledger/trusted-sources`
  - 目录修改只影响未来来源分级；历史证据、候选、评分和人工审批必须保持不变。

### 台账字段

- 人工材料证据使用 `evidence_origin = human_attested_material` 和
  `collection_method = human_authorized_submission`。
- 人工提交审计位于 `human_evidence_submissions`；附件原文和快照路径不能通过列表接口返回。
- 人工材料结果使用 `feedback_kind = human_material_source_learning_only` 且
  `score_snapshot_id = null`，并固定记录 `source_evidence_ids` 与 `source_domains`，以防
  一次结果误归因到同线索的其他来源。
- 学习策略和策略审计分别位于 `adaptive_learning_policy` 与
  `adaptive_learning_policy_audit`。

### 必须保持的安全性质

1. 人工材料不得进入自动事实分类、风险词预警、自动评分或评分权重学习。评分器只使用
   非 `human_attested_material` 的服务器材料。
2. 人工结果反馈只能追加 `outcome_feedback`；不得改写线索、证据、来源目录、学习策略或
   历史反馈。
3. 所有写接口都必须经过共享台账成员守卫；浏览器不得提供用户 ID、时间、签名、哈希、
   本机路径或证据 ID。
4. 服务器不得代替用户登录、读取 Cookie、执行受限网页脚本或绕过 robots。
5. 自动学习最多改变队列顺序和经用户显式授权的固定配方顺序；不得自动创建来源、关键词、
   证据、招商结论或外部消息。

## 排查表

| 现象 | 正常原因 | 处理方式 |
| --- | --- | --- |
| “服务器重新核验”失败 | 原页面变化、访问限制、草稿字段不足或范围条件未满足 | 阅读失败阶段和原因；补充公开材料，或走人工材料通道，但不要伪造服务器抓取 |
| 人工材料没有提高机器评分 | 这是设计边界，人工材料不参与自动评分 | 由业务人员完成交叉核对和招商审批；评分只等待服务器材料 |
| 来源学习显示“样本不足” | 单一来源的可用材料/结果少于最小样本量 | 继续如实记录材料与实际结果，不应人为刷样本 |
| 新登记来源没有立刻出现候选 | 目录登记不触发抓取，且服务器仍遵守 robots 和访问安全规则 | 等待下一次固定监控，或由人以合法材料补充 |
| 团队成员看不到材料或学习页面 | 登录账号尚未进入徐州招商团队名册 | 管理员在业务页“管理员 → 徐州团队名册”添加平台用户名 |
