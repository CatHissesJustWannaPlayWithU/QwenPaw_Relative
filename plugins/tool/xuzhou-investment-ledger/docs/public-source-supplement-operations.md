# 人工补充公开来源：业务操作与维护说明

这项功能解决的是“业务人员知道一个公开网站，但系统当前固定来源目录没有它”的问题。它
不是给浏览器一个任意抓取权限，也不是把网址加入后立刻得出招商结论。

## 先选对通道

| 你手中的信息 | 应该使用什么 | 机器会做什么 | 不会做什么 |
| --- | --- | --- | --- |
| 无需登录即可打开的普通网页 | 人工补充公开来源 | 安全检测；通过后低频发现候选 | 直接入证、认定事实、联系企业 |
| 你有权登录才能看的网页、文件或导出 | 人工材料入账 | 保存你的摘录、访问方式、提交人、时间和哈希 | 使用你的账号、Cookie 或密码再次登录 |
| 付费数据、API、需要 API Key 的接口 | 开发者后端接入 | 由开发者按供应商许可设计服务端连接 | 在业务页面接受密钥、令牌或 API URL |
| 已在目录内的固定来源 | 可信来源目录 | 按现有规则监控或分级 | 自动扩大到不相关网站 |

## 业务人员：提交后每一步发生什么

1. 在业务页或 QwenPaw 工作台的“可信来源目录”找到“人工补充公开来源”，填写完整网址，
   例如 `https://example.com/news`，可选填写这是什么网站。
2. **服务器先做本地安全检查**：仅允许 HTTP/HTTPS、公开 ASCII 域名、默认端口；拒绝 IP、
   内网/本机地址、用户名密码、查询参数、片段和疑似 API 路径。此时不会保存失败网址。
3. **服务器读取 robots 规则**：网站不允许机器读取时，结果显示“网站不允许机器抓取”。
   你可以走人工材料入账，但不能让系统绕过 robots。
4. **服务器只访问这一条公开网页**：检查公开访问、内容类型、响应大小与重定向。重定向到
   其他域名会被拒绝；需要登录、会员、验证码或付费访问则不会登记。
5. 全部通过后才写入团队来源目录，记录提交人、时间、原始入口、检测结果和审计说明。
   这时的状态是“服务器可直接抓取”。
6. 在之后的固定低频来源监控中，系统最多选少量已通过的人工补充来源，读取登记网址以及
   同域、robots 允许的少量 RSS、Sitemap 和首页链接，生成**待人工核验候选**。
7. 业务人员仍须阅读候选或服务器保存的页面材料，作业务判断；需要形成正式证据时，仍须
   按原有“服务器重新核验并入证”流程通过。新增来源本身不等于证据、招商价值、企业意愿
   或招商成功。

## 检测结果怎么处理

| 页面显示 | 意味着什么 | 业务人员下一步 |
| --- | --- | --- |
| 服务器可直接抓取 | 此刻公开访问、robots 和安全检查通过 | 保持启用，等待低频计划发现候选；必要时可重新检测 |
| 网站不允许机器抓取 | 站点 robots 规则拒绝自动访问 | 不要反复点击；有权使用内容时走人工材料入账 |
| 需要登录、会员或付费访问 | 服务器没有也不会索取访问权限 | 不要粘贴密码、Cookie 或令牌；人工材料或开发者许可接入 |
| 看起来是 API / 带凭据入口 | 不适合业务页面直接抓取，可能有密钥或供应商限制 | 交给开发者做后端接入；不要把 API Key 发给系统 |
| 暂时无法访问 | DNS、连接、站点暂时故障或不稳定 | 稍后点击“重新检测”；失败不删除历史审计 |
| 不是可安全访问的公开网站 | 地址不符合安全边界或跳转出登记域名 | 改用正常公开网页；内网/IP 地址不能提交 |

## 权限、数量和停用

- 徐州团队名册内、已登录的成员可以提交、重新检测、启用或暂停自己团队共享的补充来源；
  服务器审计每一次实际操作者。
- 最多同时启用 8 个补充来源；低频计划每次最多从这类来源中选 2 个，且仍受全局来源预算
  限制，避免一个人加入的网址挤占所有原有来源。
- “暂停”不联网：它只停止未来自动发现，历史候选、材料和审计仍保留。
- “重新检测并启用”会重新检查同一个服务器保存的网址，浏览器不能借此换成另一个网址。
- 同一域名已有已启用补充来源时，通用可信来源登记不能自动替换它。若确实要改成独立的
  可信来源规则，先暂停补充来源，再由业务人员按来源级别、可支持事实类别等单独登记。

## 给开发者的接口与不变量

所有接口都在认证与徐州团队成员守卫之后调用；客户端身份从认证主体取得，不接受用户 ID。

- `GET /api/xuzhou-investment-ledger/public-sources`：只读已登记来源和上次检测结果，不联网。
- `POST /api/xuzhou-investment-ledger/public-sources/preflight`：只检测一个网址，不落库。
- `POST /api/xuzhou-investment-ledger/public-sources`：再次检测并登记；失败绝不写入来源目录。
- `POST /api/xuzhou-investment-ledger/public-sources/{source_id}/retest`：只重新检测服务器已保存
  的入口，不能在请求中换 URL。
- `POST /api/xuzhou-investment-ledger/public-sources/{source_id}/status`：暂停不联网；启用必须由
  服务端对保存入口再次预检通过。

维护时必须保持：不接受 Cookie、密码、令牌、请求头、搜索词、抓取深度或正文；不访问内网
目标；不绕过 robots；不跟随跨域重定向；不把候选、抓取成功或来源登记升级为正式证据；不让
学习模块自动新增或升级来源。付费/API 集成应单独设计最小权限密钥管理、供应商许可验证、
速率限制、审计和故障隔离，不能复用本业务页面的提交入口。
