# 从公开材料到招商跟进：业务人员操作说明

这份说明面向招商业务人员。系统不会把一篇新闻、一个网页链接或一条“已入证”记录直接
说成“企业会来徐州”。每一步都有明确的机器职责和人工职责。

## 一句话流程

`网页消息 → 服务器留存材料或人工授权材料 → 可追溯入账材料 → 人工招商审批 → 人工跟进 → 人工确认结果`

其中，机器是“情报员、档案员、质检员和提醒员”；人是“招商判断人和实际执行人”。

## 第 1 步：机器发现公开网页

机器做什么：在已允许的公开来源和固定低频计划中发现网页链接，保存标题、网址和搜索
摘要。它不会把摘要当成企业事实，也不会联系企业。

业务人员做什么：通常不需要操作。若看到“仅有链接、尚未保存材料”，应理解为服务器还
没有保存该网页的可复查副本、可见正文、采集时间和内容哈希。直接在浏览器打开网页不等
于系统已经留存材料。

## 第 2 步：机器保存页面材料；人阅读材料

机器做什么：访问允许抓取的原网页，保存当时的页面副本、正文、采集时间和内容哈希。
这些材料会保留，以便日后说明“系统当时看到了什么”。若网页只有业务人员能合法打开，
机器不会借用人的账号；业务人员可另走“人工材料入账”，把自己有权使用的关键摘录、导出
文本或小型附件连同访问方式登记进台账。两类材料在页面和审计中始终分开标识。

业务人员做什么：点击“查看材料”，只回答以下问题：

- 这篇材料说的是否确实是页面列出的企业或基金？
- 页面是否明确说了融资、扩产、合作、研发、选址或其他值得关注的事项？
- 它是否只是广告、导航、拼接内容，或与徐州招商范围无关？

此时可选择“待补证”“观察”或“不纳入”。这些是业务处置记录，不会修改原网页材料。

## 第 3 步：服务器重新核验，或由人登记授权材料

服务器重新核验做什么：当用户发起“请求重新核验并入证”时，服务器重新访问同一原网页，
并依次检查页面能否访问、主体名称、发布日期、关键摘录和来源条件是否仍然匹配。全部通过
才会新增一条**服务器核验材料**，并保留证据编号和原始快照。

业务人员做什么：确认草稿是否值得请求核验；不能在页面上修改日期、企业名、网址或原文。
若服务器提示失败，应先阅读明确原因：例如缺发布日期、主体不匹配、原文已变化或网页不
允许访问。然后可以选择等待补证、观察或不纳入；如果你本人能合法阅读或导出该材料，也可
登记为**人工授权材料**。人工材料会记录提交人、时间、内容哈希和访问方式，但不会被写成
“服务器已经抓取”。

“服务器核验材料”的含义仅是：某个公开事实可以追溯、复查和引用。“人工授权材料”的
含义是：有授权的业务人员为内部研判提交了可追溯材料。二者都不表示企业已同意投资、已
同意来徐州或已经成为招商成果。

## 第 4 步：业务人员填写招商跟进审批卡

只有至少一条可追溯入账材料存在时，线索详情会显示“第 3 步：人工招商跟进决定”。机器
在这张卡中只做三件事：分别显示服务器材料与人工材料数量、提示已记录风险、记录审批与
下一步。机器不会替人判断招商价值。若包含人工材料，审批人必须额外完成主体、关键事项
和独立来源的交叉核对。

业务人员需要逐项确认：

1. 企业主体与材料所述对象一致；
2. 已逐项阅读服务器材料和/或人工授权材料，并清楚知道其来源方式；
3. 与徐州目标产业或载体存在业务匹配；
4. 已核对徐州/中国业务依据；若没有“徐州”字段，已写明仍纳入研判的原因；
5. 融资、扩产等关键事项已由一手公开来源或独立公开来源交叉核对；
6. 已处理风险、矛盾和时效问题；
7. 写清招商价值、负责人、下一步动作和完成日期。

审批人是已被管理员加入徐州招商团队名册的登录用户。系统会记录登录用户、时间、所引用
的证据编号、业务理由、负责人和行动计划；审批人不能修改任何原始网页或正式证据。

## 第 5 步：人工跟进

审批通过后的状态叫“已纳入招商跟进池”。它只表示团队认可该线索值得安排后续工作。

机器做什么：保留审批卡、在工作台中显示负责人和日期，并继续按既有规则提供日报、待办
和证据查看能力。它不会自动向企业发送钉钉、微信、邮件或电话，不会承诺政策，也不会把
内部计划发送给外部主体。

业务人员做什么：按审批卡所写动作完成调研、产业匹配、公开官方信息核实、内部研判或由
人工决定的初步沟通。实际对接应使用单位认可的合规渠道，并由人自行判断沟通内容。

## 第 6 步：确认实际结果

只有在人工获得可核对的真实结果后，才能记录“已接触”“已会谈”“暂不推进”“已落地”
或签约、投资额等成果。系统的线索数量、评分、日报数量和“已纳入跟进池”数量都不等于
招商成功率，更不等于企业已作出投资承诺。

## 常见误解

| 页面文字 | 实际含义 | 不是 |
| --- | --- | --- |
| 已保存页面材料 | 服务器保存了网页副本和校验信息 | 服务器已经确认招商结论 |
| 人工授权材料 | 有授权的业务人员提交了可追溯摘录/文件，并留下实名、时间和访问方式 | 服务器已经登录、抓取或核验了该网页 |
| 服务器核验材料 | 公开事实可回溯、可复查 | 企业愿意来徐州 |
| 待补证 | 当前材料缺少某项可复查依据 | 业务人员必须伪造或修改网页 |
| 观察 | 暂不投入更多人工时间，但保留低频关注 | 已经同意招商推进 |
| 已纳入招商跟进池 | 团队完成审批并指定负责人和下一步 | 企业签约、投资或落地 |

## 给维护人员的边界

- 审批卡的写接口不接收 URL、网页正文、摘录、评分、证据 ID 或操作者 ID；这些内容只能
  来自服务器已有台账和认证会话。
- 审批只能追加 `lead_followup_approval_audit`，并更新对应线索的业务状态和状态历史；
  保存前会逐字检查可追溯入账材料、候选材料、评分和证据关联没有变化。
- 泛化线索复核接口不再允许 `advance`；任何“推进”必须走完整审批卡。
- 审批卡保存的是内部业务计划，不得解释为企业投资意愿、对外承诺、签约或招商成果。
