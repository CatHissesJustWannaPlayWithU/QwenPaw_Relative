# 徐州招商线索与证据台账

## 页面内使用手册

QwenPaw 的“徐州招商工作台”标题区提供“使用手册”入口。手册以四页说明完整业务流程、
业务人员/机器/管理员的权限边界、各功能与状态，以及开发维护和扩展顺序。手册是只读说明，
不会因为打开、切换或关闭而调用业务接口或修改台账。

独立业务页也提供同名入口，使用更口语化的六步流程和“今天怎么做”说明。两端必须保持
相同的证据边界：机器保存和核验材料，人类决定招商价值和实际行动；任何“入证”“入池”
都不代表企业已同意、已签约或已落地。

第一模块用于把已经取得的公开信息登记为可追溯线索，不负责自动招商动作或投资结论。正式
证据之后，工作台会提供一张独立的“招商跟进审批卡”：机器只核对已有证据并保留审计；
已获团队授权的业务人员必须逐项确认主体、证据、产业、地域、交叉核验、风险处理、负责人
和下一步，才可将线索标记为“已纳入招商跟进池”。这不代表企业已同意来徐州、已签约或会
收到系统自动外联。

## 数据边界

- 徐州团队使用一份服务端授权的共享台账；平台账号和团队名册是两个独立的授权环节，操作按用户留痕。
- 机器可按规则发现公开网页并保存页面材料；网页标题、快照和人工提交材料不会自动变成经核验的事实。
- 业务人员审核证据和跟进价值；即使通过内部审批，也不代表企业已同意投资、签约或落地。
- 人工材料保留来源和提交记录，不能冒充服务器抓取结果；学习规则受团队授权约束，不会自动修改证据或对外联系。

## 人工补充公开来源

团队成员可在“可信来源目录”的“人工补充公开来源”区域提交一个**不需要登录、Cookie、令牌、
API Key 或付费权限**的公开网页。服务器会先检查网址安全性、robots 规则、公开访问能力和
同域跳转；通过后，它只能作为低频候选发现入口，绝不会直接变成正式证据、招商结论或自动
外联。

- 付费 API、需要授权的数据接口以及任何带参数的临时链接不能由业务页面提交。它们必须由
  开发者在后端源码与密钥配置中，按供应商许可单独接入。
- 人能合法打开、服务器却不能读取的页面，应走“人工材料入账”，不要提供账号、Cookie、
  密码或访问令牌。
- 同一个已启用的人工补充域名不能被通用“可信来源目录”自动替换或升级；先暂停它，再由
  业务人员登记独立的可信来源规则，避免跳过服务器重新检测。

完整的业务操作、状态解释、接口和维护不变量见
[人工补充公开来源操作说明](docs/public-source-supplement-operations.md)。

双端手册的内容位置和同步规则见
[双端页面内使用手册维护说明](docs/in-product-usage-guide.md)。

## 核心工具示例

- `list_xuzhou_investment_leads`：按产业或复核状态查询线索。
- `get_xuzhou_investment_lead`：查看单条线索和完整证据链。
- `get_xuzhou_investment_action_center`：只读汇总需要人工处理的事项。

## 使用边界

- 公开来源监控只在计划启用、来源规则允许的情况下运行，仍需人工复核。
- 不计算招商成功概率，不给企业下确定性投资结论，也不自动联系企业。
- 账号管理、团队授权和证据操作均以服务端权限校验为准。
